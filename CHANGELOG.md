# Changelog

## 2.2.0 — First public release
- A + on every ranked war item (yellow, orange or red weapons and armour), whatever its bonus
- Works in the faction armoury, Items, auction house, Item Market, bazaars, display cases and trades
- Notes are tied to one exact item by its stats (name, damage, accuracy or armour, quality and bonuses), with the weapon UID as a fallback
- The same item is recognised across pages, so its note follows it
- The + sits at the end of the item's first description line, so long descriptions can't hide it
- Solid orange + shows an item already has a note
- Add, edit and delete notes (up to 300 characters); Ctrl+Enter saves, Esc closes
- Notes sync across open Torn tabs
- Torn PDA support
- Read-only: no requests, no API key, nothing sent anywhere
